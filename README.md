# Airton Adams | Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos e formas de contato como desenvolvedor front-end.

## Visão geral

Este projeto foi construído com foco em uma experiência moderna, responsiva e visualmente atrativa, com a proposta de funcionar como cartão de apresentação digital para clientes, recrutadores e parceiros.

## Demo

Acesse o projeto em produção:

https://portifolio-nine-blond.vercel.app/

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Swiper
- GitHub API

## Recursos

- Layout responsivo para mobile, tablet e desktop
- Seção de apresentação pessoal
- Área de projetos com cards dinâmicos
- Integração com o GitHub para exibir repositórios
- Formulário de contato
- Botão para download do currículo

## Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/AirtonAdams/portifolio.git
```

2. Acesse a pasta do projeto:

```bash
cd portifolio
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Abra no navegador a URL informada pelo Vite.
